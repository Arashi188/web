# EliteStore - Production E-Commerce Website

A fully functional e-commerce website built with Python Flask, featuring a professional UI, product management, shopping cart, WhatsApp checkout, and admin dashboard.

## Features

### Customer Features
- Browse products with search and category filters
- Product detail pages
- Shopping cart management
- WhatsApp checkout integration
- User registration and login
- Responsive design for all devices

### Admin Features
- Secure admin dashboard
- Add/Edit/Delete products
- Manage orders and update status
- View order details
- Product image upload via Cloudinary

## Technology Stack

- **Backend**: Python Flask, Flask-SQLAlchemy, Flask-Login
- **Frontend**: HTML5, CSS3, Bootstrap 5, JavaScript
- **Database**: PostgreSQL (compatible with Supabase)
- **Storage**: Cloudinary for image hosting
- **Deployment**: Render.com ready
